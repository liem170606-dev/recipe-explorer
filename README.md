# Recipe Explorer — ספר המתכונים העולמי 🍳

אפליקציית Web אינטראקטיבית מרובת-עמודים שנבנתה עם **React + Vite + TypeScript + React Router + Vitest** לגילוי, חיפוש, סינון ושמירת מתכונים מרחבי העולם, כפרויקט גמר בקורס **4255 · פלטפורמות מתקדמות לפיתוח ב-WEB ושימוש ב-AI**.

---

## 📌 מה האפליקציה עושה?

- **ניתוב מרובה-עמודים (React Router):**
  - **דף הבית (`/` — `HomePage.tsx`):** דף נחיתה והסבר המציג את יתרונות האתר, סטטיסטיקות, טעימה ממנות נבחרות, וכפתורי כניסה לקטלוג ולדף ההפתעה.
  - **קטלוג המתכונים (`/meals` — `MealsPage.tsx`):** גריד מלא של כל המתכונים, חיפוש דו-לשוני בזמן אמת, סינון לפי קטגוריות ופילטר מועדפים.
  - **דף מתכון ייעודי (`/meals/:id` — `MealDetailPage.tsx`):** דף נפרד ועצמאי לכל מתכון הקורא את ה-`id` מהכתובת באמצעות `useParams()`, עם תמונה גדולה, רשימת מצרכים וכמויות בעברית, שלבי הכנה ממוספרים, קישור ישיר ל-YouTube וכפתור חזרה לקטלוג.
  - **עמוד המועדפים שלי (`/favorites` — `FavoritesPage.tsx`):** עמוד ייעודי המרכז את כל המתכונים שסומנו בכוכב ונשמרו ב-`localStorage`, עם אפשרות הסרה פרטנית או ניקוי כל הרשימה.
  - **עמוד הפתעה וסטטיסטיקות (`/discover` — `DiscoverPage.tsx`):** עמוד אינטראקטיבי הכולל מחולל מתכון אקראי ("מה מבשלים היום?") ולוח סטטיסטיקות חי המתפלג לפי קטגוריות ומטבחים בעולם.
  - **עמוד 404 (`*` — `NotFoundPage.tsx`):** עמוד שגיאה ידידותי לכל כתובת שאינה קיימת עם קישורי חזרה לדף הבית ולקטלוג.
- **TypeScript מלא ומוקפד:** הגדרת ממשקים (`interface`) ב-`src/types/meal.ts` ובכל רכיבי האפליקציה (`Props`), ללא שימוש ב-`any`.
- **חיפוש וסינון בזמן אמת:** שדה חיפוש טקסטואלי חופשי דו-לשוני (עברית ואנגלית), סינון לפי קטגוריות מנות, ומונה תוצאות דינמי.
- **מצבי רשת מלאים:** טיפול בשלושה מצבי מסך — אנימציית טעינה (Loading Spinner), מסך שגיאה ברור עם אפשרות לניסיון חוזר (Retry), ותצוגת נתונים מלאה.
- **שמירת מועדפים קבועה ב-`localStorage`:** סימון מתכונים בכוכב (★) נשמר אוטומטית בדפדפן ומוצג בסרגל הניווט ובעמוד `/favorites`.

## 🌐 ה-API שבו השתמשנו

האפליקציה שולפת 100% מנתוני המתכונים בזמן אמת מה-API הציבורי החינמי של **TheMealDB** (ללא מפתח API):
- **שליפת רשימת המתכונים:** `https://www.themealdb.com/api/json/v1/1/search.php?s=`
- **שליפת מתכון פיצה מרגריטה לפי מזהה:** `https://www.themealdb.com/api/json/v1/1/lookup.php?i=53014`
- **מידע המתקבל לכל מנה:**
  - מזהה ייחודי (`idMeal`) המשמש לניתוב (`/meals/:id`) ול-`key` ברינדור הרשימות.
  - שם המנה (`strMeal`), קטגוריה (`strCategory`), ארץ מוצא (`strArea`), ותמונת המנה (`strMealThumb`).
  - רשימת מצרכים וכמויות (`strIngredient1..20`, `strMeasure1..20`).
  - הוראות הכנה מלאות וסרטון הדרכה ב-YouTube (`strYoutube`).

## 🚀 איך מריצים את הפרויקט ואת הבדיקות?

1. **התקנת תלויות:**
   ```bash
   npm install
   ```

2. **הרצת שרת הפיתוח:**
   ```bash
   npm run dev
   ```
   האפליקציה תיפתח בכתובת המקומית: `http://localhost:5173`.

3. **הרצת בדיקות היחידה והרכיבים (Vitest בטרמינל — 24 בדיקות):**
   ```bash
   npm test
   ```

4. **הרצת הבדיקות בממשק הדפדפן (Vitest UI):**
   ```bash
   npm run test:ui
   ```

5. **בדיקת טיפוסי TypeScript ובניית גרסת Production:**
   ```bash
   npm run build
   ```

6. **בדיקת איכות קוד (Lint):**
   ```bash
   npm run lint
   ```

## 🧱 פירוק לרכיבים (Component Architecture)

לפירוט מלא ותרשים זרימת הנתונים ראו [docs/architecture.md](docs/architecture.md).
כל רכיבי האפליקציה כתובים ב-TypeScript ו-React (`.tsx`), ונמצאים בתיקייה `src/components/`:

1. **`src/App.tsx` (רכיב האב):** מנהל את ה-state המרכזי (`meals`, `loading`, `error`, `favorites`), מבצע את קריאות ה-`fetch` ב-`useEffect`, ומגדיר את הניתוב ב-`<Routes>`.
2. **`src/components/Navbar.tsx`:** סרגל ניווט עליון קבוע עם `NavLink` ל-4 העמודים הראשיים ומונה מועדפים חי.
3. **`src/components/HomePage.tsx` (`/`):** דף נחיתה המסביר על האתר, מציג יתרונות ומנות מומלצות.
4. **`src/components/MealsPage.tsx` (`/meals`):** דף הקטלוג הראשי הכולל חיפוש דו-לשוני, סינון קטגוריות וגריד כרטיסי מנות.
5. **`src/components/MealDetailPage.tsx` (`/meals/:id`):** דף מתכון עצמאי המחלץ את ה-ID מהכתובת עם `useParams()`, מציג מצרכים, שלבי הכנה בעברית וקישור ל-YouTube.
6. **`src/components/FavoritesPage.tsx` (`/favorites`):** עמוד מועדפים ייעודי המציג את המנות השמורות ב-`localStorage` ומאפשר ניקוי או הסרה.
7. **`src/components/DiscoverPage.tsx` (`/discover`):** עמוד הפתעה וסטטיסטיקות הכולל הגרלת מתכון אקראי וגרפים של התפלגות קטגוריות ומטבחים.
8. **`src/components/NotFoundPage.tsx` (`*`):** עמוד 404 לכתובת שאינה קיימת.
9. **`src/components/MealCard.tsx`:** כרטיס מנה מקושר (`<Link to={/meals/${meal.idMeal}}>`) עם כפתור מועדפים (`e.preventDefault()` ו-`e.stopPropagation()`).
10. **`src/components/MealList.tsx`:** גריד רספונסיבי המרנדר את כרטיסי המנות באמצעות `.map()` עם `key={meal.idMeal}`.
11. **`src/components/SearchBar.tsx`:** שדה חיפוש טקסטואלי, בחירת קטגוריה, סינון מועדפים וכפתור איפוס.
12. **`src/components/StatusView.tsx`:** תצוגת מצב טעינה (Spinner) ומצב שגיאה עם כפתור "נסו שוב".
13. **`src/utils/translations.ts` & `src/types/meal.ts`:** הגדרות הטיפוסים ופונקציות העזר לתרגום, סינון (`filterMeals`) וחישוב סטטיסטיקות (`computeMealStats`).
