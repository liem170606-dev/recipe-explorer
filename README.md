# Recipe Explorer — ספר המתכונים העולמי 🍳

אפליקציית Web אינטראקטיבית מרובת-עמודים (**React Router**) לגילוי, חיפוש ושמירת מתכונים מרחבי העולם, שנבנתה כפרויקט גמר בקורס **4255 · פלטפורמות מתקדמות לפיתוח ב-WEB ושימוש ב-AI**.

---

## 📌 מה האפליקציה עושה?

- **ניתוב מרובה-עמודים (React Router):**
  - **דף הבית (`/`):** דף נחיתה והסבר מרהיב המציג את יתרונות האתר, סטטיסטיקות, טעימה ממנות נבחרות, וכפתור כניסה מרכזי לקטלוג.
  - **קטלוג המתכונים (`/meals`):** גריד מלא של כל המתכונים, חיפוש דו-לשוני בזמן אמת, סינון לפי קטגוריות וכפתור מועדפים.
  - **דף מתכון ייעודי (`/meals/:id`):** דף נפרד ועצמאי לכל מתכון עם תמונה גדולה, רשימת מצרכים מפורטת בעברית, שלבי הכנה ממוספרים, כפתור יוטיוב ישיר וכפתור חזרה לקטלוג.
- **חיפוש וסינון בזמן אמת:** שדה חיפוש טקסטואלי חופשי דו-לשוני (עברית ואנגלית), סינון לפי קטגוריות מנות, ומונה תוצאות דינמי.
- **מצבי רשת מלאים:** טיפול בשלושה מצבי מסך — אנימציית טעינה (Loading Spinner), מסך שגיאה ברור עם אפשרות לניסיון חוזר (Retry), ותצוגת נתונים מלאה.
- **שמירת מועדפים קבועה:** אפשרות לסמן מתכונים מועדפים בכוכב (★), שמירה אוטומטית בדפדפן באמצעות `localStorage`, ומונה מועדפים חי בסרגל הניווט.
- **עיצוב אישי רספונסיבי:** קובץ CSS עצמאי (`index.css`) ללא ספריות UI חיצוניות, מותאם באופן מלא גם למסכי סמארטפון צרים (Mobile Responsive).

## 🌐 ה-API שבו השתמשנו

האפליקציה מתחברת ל-API הציבורי של **TheMealDB**:
- **כתובת ה-API:** `https://www.themealdb.com/api/json/v1/1/search.php?s=`
- **החלפת מנות אותנטית:** מנת הפאייה הוחלפה במתכון אותנטי של **פיצה מרגריטה איטלקית קלאסית** (ID: 53014) מתוך ה-API.
- **מידע המתקבל לכל מנה:**
  - מזהה ייחודי (`idMeal`) המשמש לראוטינג (`/meals/:id`) ול-`key` ברינדור הרשימה.
  - שם המנה (`strMeal`), קטגוריה (`strCategory`), ארץ מוצא (`strArea`), ותמונת המנה (`strMealThumb`).
  - רשימת מצרכים וכמויות (`strIngredient1..20`, `strMeasure1..20`).
  - הוראות הכנה מלאות וסרטון הדרכה ביוטיוב.

## 🚀 איך מריצים את הפרויקט?

1. **התקנת תלויות:**
   ```bash
   npm install
   ```

2. **הרצת שרת הפיתוח:**
   ```bash
   npm run dev
   ```
   האפליקציה תיפתח בכתובת המקומית: `http://localhost:5173`.

   ```bash
   npm run lint
   ```

4. **בניית גרסת Production:**
   ```bash
   npm run build
   ```

5. **הרצת בדיקות אוטומטיות (Vitest — חובה לפי מחוון):**
   ```bash

   ```

   ```bash
   npm run test:watch
   ```

## 🧱 פירוק לרכיבים (Component Architecture)

כל רכיבי האפליקציה כתובים ב-JavaScript פשוט ו-React, ונמצאים בתיקייה `src/components/`:

1. **`App.jsx` (רכיב האב):**
   - מנהל את ה-state המרכזי של המערכת (`meals`, `loading`, `error`, `favorites`).
   - מגדיר את הניתוב עם `Routes` ו-`Route` עבור דף הבית, הקטלוג ודף המתכון.

2. **`Navbar.jsx`:**
   - סרגל ניווט עליון קבוע עם לוגו, קישורים לדף הבית ולקטלוג, ומונה מועדפים חי.

3. **`HomePage.jsx` (`/`):**
   - דף נחיתה מעוצב שמסביר על האתר, מציג סטטיסטיקות, כרטיסי יתרונות ומנות מומלצות, וכולל כפתור כניסה לקטלוג.

4. **`MealsPage.jsx` (`/meals`):**
   - דף הקטלוג הראשי הכולל את שורת החיפוש הדו-לשוני, סינון קטגוריות, סינון מועדפים, וגריד מלא של כרטיסי המנות.

5. **`MealDetailPage.jsx` (`/meals/:id`):**
   - דף מתכון מלא ועצמאי המחלץ את ה-ID בעזרת `useParams()`, מציג את כל פרטי המנה, מצרכים והוראות בעברית, יוטיוב, וכפתור חזרה לקטלוג.

6. **`MealCard.jsx`:**
   - כרטיס מנה מקושר (`<Link to={/meals/${meal.idMeal}}>`) עם תמונה, שם ותגיות, וכפתור כוכב עם `stopPropagation` ו-`preventDefault`.

7. **`MealList.jsx`:**
   - גריד רספונסיבי מלא המרנדר את כרטיסי המנות עם `key={meal.idMeal}` והודעת ריקנות כשאין תוצאות.

8. **`SearchBar.jsx`:**
   - שדה חיפוש טקסטואלי, תפריט בחירת קטגוריות, כפתור מועדפים וכפתור איפוס סינונים.

9. **`StatusView.jsx`:**
   - מנהל את מצב הטעינה (ספינר מסתובב) ומצב שגיאה ברשת עם כפתור "🔄 נסו שוב".

10. **`src/utils/translations.js` (שכבת תרגום והעשרה):**
    - מתרגם 100% משמות המנות, הקטגוריות, ארצות המוצא, המצרכים ויחידות המידה לעברית שוטפת.
    - מספק הוראות הכנה מלאות וממוספרות בעברית לכל המתכונים.
    - משלים מצרכי מפתח חיוניים שהושמטו ב-API (כמו סלמון/טונה ואצות נורי לסושי).
    - מבטיח קישור ישיר לסרטון הדרכה ב-YouTube ל-100% מהמתכונים.

## 💡 מענה לשאלות הגנה טכניות (7 דקות מול המרצה)

- **איך ממומש הניתוב ואיזה דפים קיימים?**
  השתמשנו ב-`react-router-dom` עם `BrowserRouter` ב-`main.jsx`. הגדרנו 3 ראוטים עיקריים:
  1. `/` — דף בית עם הסבר והיילייטס.
  2. `/meals` — קטלוג כל המתכונים עם סינון וחיפוש.
  3. `/meals/:id` — דף מתכון עצמאי שנשלף דינמית לפי מזהה המנה בעזרת `useParams()`.
- **איפה נשמר ה-State המרכזי?**
  ברכיב `App.jsx` לפי עקרון **Lifting State Up**, כדי שהנתונים (`meals`, `favorites`, `loading`) יהיו משותפים לכל הדפים והסרגל העליון ללא צורך בספריות ניהול מצב חיצוניות.
- **איך נמנע ניווט בלחיצה על כוכב המועדפים בכרטיס?**
  בכפתור הכוכב ב-`MealCard.jsx` הוספנו `e.preventDefault()` ו-`e.stopPropagation()`. זה עוצר את פעפוע האירוע ומונע מהלינק לנווט לדף המתכון כשרוצים רק לסמן מועדף.
- **כיצד עובד הבונוס של המועדפים?**
  המועדפים נשמרים ב-`localStorage`. בטעינת האפליקציה הם נטענים אוטומטית, ובכל שינוי `useEffect` ייעודי שומר את המערך המעודכן.
