# Recipe Explorer — ספר המתכונים העולמי 🍳

אפליקציית Web אינטראקטיבית לגילוי, חיפוש ושמירת מתכונים מרחבי העולם במבנה **Master-Detail**, שנבנתה כפרויקט גמר בקורס **4255 · פלטפורמות מתקדמות לפיתוח ב-WEB ושימוש ב-AI**.

---

## 📌 מה האפליקציה עושה?

- **תצוגת Master-Detail מודרנית:** רשימת כרטיסי מתכונים עשירה, ולצידה פאנל פרטים נגלל המציג תמונה מוגדלת, רשימת מצרכים מפורטת עם כמויות, והוראות הכנה צעד-אחר-צעד.
- **חיפוש וסינון בזמן אמת:** שדה חיפוש טקסטואלי חופשי לפי שם המנה, סינון לפי קטגוריות מנות (Pasta, Seafood, Chicken, Vegetarian ועוד), ומונה תוצאות דינמי.
- **מצבי רשת מלאים:** טיפול בשלושה מצבי מסך — אנימציית טעינה (Loading Spinner), מסך שגיאה ברור עם אפשרות לניסיון חוזר (Retry), ותצוגת נתונים מלאה.
- **בונוס איכות — שמירת מועדפים:** אפשרות לסמן מתכונים מועדפים בכוכב (★), שמירה קבועה בדפדפן באמצעות `localStorage`, וכפתור סינון ייעודי להצגת מועדפים בלבד.
- **עיצוב אישי רספונסיבי:** קובץ CSS עצמאי (`index.css`) ללא ספריות UI חיצוניות, מותאם באופן מלא גם למסכי סמארטפון צרים (Mobile Responsive).

---

## 🌐 ה-API שבו השתמשנו

האפליקציה מתחברת ל-API הציבורי והחינמי של **TheMealDB** (ללא צורך במפתח API):
- **כתובת ה-API:** `https://www.themealdb.com/api/json/v1/1/search.php?s=`
- **מידע המתקבל לכל מנה:**
  - מזהה ייחודי (`idMeal`) שמשמש כ-`key` ברינדור הרשימה.
  - שם המנה (`strMeal`), קטגוריה (`strCategory`), ארץ מוצא (`strArea`), ותמונת המנה (`strMealThumb`).
  - רשימת מצרכים וכמויות (`strIngredient1..20`, `strMeasure1..20`).
  - הוראות הכנה מלאות (`strInstructions`) וסרטון הדרכה (`strYoutube`).

## 🧱 פירוק לרכיבים (Component Architecture)

כל רכיבי האפליקציה כתובים ב-JavaScript פשוט ו-React בלבד, ונמצאים בתיקייה `src/components/`:

1. **`App.jsx` (רכיב האב):**
   - מנהל את כל ה-state המרכזי של המערכת.
   - מבצע את קריאת ה-`fetch` בתוך `useEffect` בעליית הדף.
   - מעביר את הנתונים והפונקציות לכל שאר הרכיבים דרך `props`.

2. **`Header.jsx`:**
   - כותרת האפליקציה, אייקון ותיאור קצר.

3. **`SearchBar.jsx`:**
   - שדה חיפוש טקסטואלי עם כפתור ניקוי מהיר (✕).
   - תפריט בחירה (dropdown) לסינון לפי קטגוריות מנות.
   - כפתור סינון מועדפים (`★ מועדפים`) עם מונה חי.
   - כפתור איפוס כל הסינונים.

4. **`MealList.jsx`:**
   - מרנדר את רשימת המנות המסוננות באמצעות מתודת `.map()`.
   - מעביר `key={meal.idMeal}` ייחודי לכל פריט.
   - מציג הודעת ריקנות ידידותית אם לא נמצאו תוצאות התואמות לחיפוש.

5. **`MealCard.jsx`:**
   - כרטיס מנה בודד המציג תמונה, שם, תגיות קטגוריה ומוצא.
   - כפתור כוכב (★) לסימון מועדף עם מניעת התפשטות אירוע לחיצה (`stopPropagation`).
   - מסומן ויזואלית כאשר הוא המנה הנבחרת כעת (`selected`).

6. **`MealDetail.jsx`:**
   - פאנל Master-Detail ייעודי המציג את כל פרטי המנה שנבחרה.
   - מחלץ באופן דינמי את צמדי המצרכים והכמויות.
   - מציג את פסקאות הוראות ההכנה וכפתור ישיר לסרטון ה-YouTube.
   - כפתור סגירה (✕) להחזרת המסך למצב התחלתי.

7. **`StatusView.jsx`:**
   - מנהל את מצב הטעינה (ספינר מסתובב) ומצב שגיאה ברשת עם כפתור "🔄 נסו שוב".

8. **`src/utils/translations.js` (שכבת תרגום והעשרה):**
   - מתרגם את שמות המתכונים, הקטגוריות, ארצות המוצא, 100% מהמצרכים ויחידות המידה לעברית עשירה ומדויקת.
   - מספק הוראות הכנה מלאות בעברית שלב-אחר-שלב לכל המתכונים.
   - משלים מצרכי מפתח שהושמטו ב-API המקורי (כמו סלמון/טונה ואצות נורי לסושי).
   - מבטיח קישור ישיר לסרטון הדרכה ב-YouTube ל-100% מהמתכונים.

## 💡 מענה לשאלות נפוצות על הקוד (הכנה לשאלון ולסרטון)

- **איפה נשמר ה-State?**
  כל ה-State נשמר ברכיב האב `App.jsx` (`meals`, `selectedMeal`, `searchTerm`, `selectedCategory`, `showOnlyFavorites`, `favorites`, `loading`, `error`).
- **מה קורה בלחיצה על כרטיס מנה?**
  מופעלת הפונקציה `onSelectMeal(meal)` שהועברה כ-prop מ-`App.jsx`. הפונקציה מעדכנת את `selectedMeal` ב-state, מה שגורם לפאנל `MealDetail` להתרנדר עם פרטי המנה שנבחרה, ולכרטיס ב-`MealList` לקבל מסגרת והדגשה.
- **כיצד מבוצעת קריאת הרשת?**
  הקריאה מבוצעת ב-`useEffect` בעת עליית האפליקציה באמצעות `fetch` מובנה בדפדפן. ישנה שמירה על 3 מצבים: `loading: true` בזמן ההמתנה, תפיסת שגיאות ב-`catch` לעדכון ה-state של `error`, ורינדור הנתונים במידה והקריאה הצליחה.
- **איך עובד הבונוס של המועדפים?**
  בעת טעינת `App.jsx`, המערך של ה-`idMeal` המועדפים נקרא מ-`localStorage.getItem('recipe_explorer_favorites')`. בכל הוספה או הסרה, `useEffect` נוסף שומר את המערך המעודכן ל-`localStorage`.
